# PTIZASOVA

**Открыть приложение: https://ojoak2.github.io/prizasova/**

Учи английский по моментам из фильмов и сериалов. Уровни как в Duolingo, без упражнений на голос. Бесплатно, без подписок и ключей.

- Напиши название фильма или сериала, например «Пацаны». Приложение найдёт его в Википедии, скачает реплики героев с Wikiquote и соберёт урок: реплика на английском и задание на перевод.
- Рядом с репликой фото героя из Википедии. Нажми на фото, и голос прочитает фразу по-английски (есть кнопка «Медленно»).
- Нажми на любое английское слово в реплике, чтобы увидеть перевод, послушать произношение и добавить слово в словарь.
- Задания: выбрать перевод, собрать перевод из слов, написать перевод самому, найти пары слов.
- Напиши «Слова» или «Слова: путешествия» (еда, работа, эмоции, дом, город, здоровье, погода, сленг, отношения), чтобы учить слова из встроенного словаря. «Слова: Пацаны» соберёт слова из реплик сериала.
- Можно загрузить скриншот с английскими субтитрами: приложение прочитает текст и сделает задания по нему.
- Жизни, опыт, серия дней, личный словарь. Прогресс хранится в браузере.

## Мини-ИИ

Реплики переводит маленькая нейросеть [opus-mt-en-ru](https://huggingface.co/Xenova/opus-mt-en-ru), которая работает прямо в браузере через [Transformers.js](https://huggingface.co/docs/transformers.js). При первом уроке она скачивается один раз (около 100 МБ), потом берётся из кэша браузера. Если скачать не получилось, приложение переводит через бесплатный сервис MyMemory.

Озвучка работает через встроенный голос телефона, без интернета. Субтитры с кадра читает [Tesseract.js](https://tesseract.projectnaptha.com/), тоже в браузере.

Перевод нейросети иногда неточный. Если твой ответ верный по смыслу, а приложение не засчитало, нажми «Мой ответ верный».

## Как запустить

Это один файл `index.html`, сервер не нужен.

1. Включи GitHub Pages: Settings → Pages → Source: «Deploy from a branch» → Branch: `main`, папка `/ (root)` → Save.
2. Через минуту приложение откроется по адресу `https://<твой-логин>.github.io/<имя-репозитория>/`.
3. На телефоне открой адрес и добавь его на главный экран.

Без интернета работает демо-урок по «Пацанам» и уроки «Слова».
