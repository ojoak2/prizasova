# PTIZASOVA

Учи английский по моментам из фильмов и сериалов. Уровни как в Duolingo, без упражнений на голос.

- Напиши название фильма или сериала, например «Пацаны». Приложение соберёт урок из 10 сцен: реплика героя на английском, задание на перевод.
- Задания: выбрать перевод, собрать перевод из слов, написать перевод самому, найти пары слов.
- Напиши «Слова» или «Слова: путешествия», чтобы учить новые слова.
- Можно загрузить свой скриншот из фильма: Claude узнает сцену и сделает задания по кадру.
- Жизни, опыт, серия дней, личный словарь. Прогресс хранится в браузере.

## Как запустить

Это один файл `index.html`, сервер не нужен.

1. Включи GitHub Pages: Settings → Pages → Source: «Deploy from a branch» → Branch: `main`, папка `/ (root)` → Save.
2. Через минуту приложение откроется по адресу `https://<твой-логин>.github.io/ptizasova/`.
3. На телефоне открой адрес и добавь его на главный экран, чтобы открывать как приложение.

## Откуда берутся уроки

Уроки по любому сериалу генерирует Claude. Подписка Claude для этого не нужна:

- открой ⚙ Настройки и вставь свой ключ Claude API (console.anthropic.com → API Keys);
- оплата идёт с баланса Anthropic за каждый запрос, примерно 10–20 центов за урок;
- ключ хранится только в твоём браузере и отправляется только на `api.anthropic.com`.

Без ключа работают встроенные демо-уроки: «Пацаны» и «Слова».

Кадры в уроках нарисованы как стилизованный экран с субтитрами: настоящие скриншоты из сериалов приложение не загружает. Реплики Claude восстанавливает по памяти, иногда не дословно.
